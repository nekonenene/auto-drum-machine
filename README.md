# Auto Drum — Sound Lab

101音色の実音と電子音をブラウザで聴き比べる、ドラムマシンの音色試作版です。

## 起動

Node.jsで `npm run dev` を実行し、`http://localhost:5173` を開きます。外部ライブラリは不要です。実音素材はリポジトリに同梱しており、起動時にローカルサーバーから約1.98MBを読み込みます。試聴中の外部通信はありません。

## 音色の調整

表示番号はカテゴリーの並びに合わせた1〜101の連番です。キックは1〜8番、スネアは9〜17番にまとめています。検索・試聴デッキ・WAVファイル名にもこの番号を使います。

| カテゴリー | 番号 |
| --- | --- |
| キック・スネア | 1〜17 |
| クラップ・ハイハット | 18〜24 |
| シンバル・タム | 25〜38 |
| 木・金属の打楽器 | 39〜45 |
| シェイカー・ハンドドラム | 46〜62 |
| 低音・音程のある音 | 63〜70 |
| 金属・粒・クリック | 71〜78 |
| ノイズ・動く音 | 79〜86 |
| リバース・スウェル | 87〜94 |
| 歪み・途切れ・空間 | 95〜101 |

- 1番のディープキックは0.32秒、30〜33番の実音タムは0.28〜0.44秒で収まる短い音にしています。
- 9〜11番のスネアは、ミュート打ち・中央打ち・リムショットの異なる実録素材を使っています。
- 10番は実音のピッチと高域を下げ、145Hzへ落ちる短い胴鳴りを重ねたファットスネアです。9・11番より低域を厚くしています。
- 12番はファミコン風のチップノイズスネアです。[NESのノイズ方式](https://www.nesdev.org/wiki/APU_Noise)を参考にした15bitの疑似乱数と段階的な音量減衰を使い、約75msでノイズが切れます。
- 19番のワイドクラップは主音を先頭に置き、後続の手拍子を6ms間隔で弱く重ねています。余韻も先頭から減衰させ、強い打撃が後から来ないようにしています。
- 25番のクラッシュに加え、26番に強打のアタッククラッシュを用意しています。Big Rusty Drumsのオーバーヘッドと近接録音を重ね、出だしの打撃を強調して軽くソフトクリップし、打撃が最初に一番大きく鳴る音にしています。余韻は2.6秒です。
- クラッシュ・ライド・ライドベル・カウベル・タムも実音を使います。スプラッシュはクラッシュの実音を高く短く加工した音、タムの中音と最低音、カウベルの高低もピッチ加工です。
- 5番は実音のアコースティックキックです。6番のロックキックはBig Rusty Drumsの24インチバスドラムの強打を使い、超低域を抑えてビーターの打撃を強調した、0.32秒で収まる音です。87〜94番はリバース5種類とスウェル3種類です。
- 13〜14番はBig Rusty Drumsの中央強打・リムショットにスナッピーの近接録音を混ぜ、高域を強調して短く減衰させたスネアです。15番は短い胴鳴りと鋭いノイズを合成したスナップスネアです。
- 34〜37番は高・中・低・最低音の電子タムです。正弦波を中心に音程を素早く下げ、0.22〜0.34秒で収まる「プン」という音にしています。30〜33番の実音タムと聴き比べられます。
- 7〜8番・16〜17番・38番はコンプ感の強いキック2音、スネア2音、タム1音です。速いアタックのコンプレッサーと軽いソフトクリップで打撃の密度を上げ、余韻は0.32〜0.40秒に収めています。検索欄の「コンプ」で5音を絞り込めます。
- スネアの音量は10番を+1dB、13番を+3dB、14番を+4dB、12番を−2dB補正しています。短いピークが高い割に小さく聞こえる実音を持ち上げ、密度の高いチップノイズを少し下げています。
- 48〜49番は実音シェイカーの短・長、52〜53番は実音タンバリンの明るい音・短い音、56〜57番は別々のボンゴの高低です。60〜62番は実音コンガの高低とミュート打ちで、高低は同じオープン打ちをピッチ加工しています。タンバリンの短い音は同じ録音の余韻を切ったものです。既存の合成音8音も隣に残し、検索欄の「リアル」で実音9音を絞り込めます。

基本のピーク音量を0.78に揃えた後、音色ごとのゲインで聴感上の音量差を補正します。増幅で0.78を超える瞬間だけ滑らかに抑え、出力のピークを0.95未満に収めています。音量補正・コンプ・胴鳴りの加工は共通のPCM生成時に行い、試聴・波形表示・保存したWAVすべてに反映されます。

同梱した22個のWAVは、CC0 1.0音源を加工したものです。

- [Virtuosity Drums](https://github.com/sfzinstruments/virtuosity_drums)（Versilian Studios / Karoryfer Samples）: 11素材。[出典と加工内容](assets/drums/README.md)、[ファイルごとの出典・ハッシュ](assets/drums/sources.json)、[ライセンス全文](assets/drums/LICENSE-CC0.txt)
- Virtuosity Drumsのパーカッション録音: シェイカー2素材、タンバリン1素材、ボンゴ2素材、コンガ2素材。[出典と加工内容](assets/percussion/README.md)、[ファイルごとの出典・ハッシュ](assets/percussion/sources.json)、[ライセンス全文](assets/percussion/LICENSE-CC0.txt)
- [Big Rusty Drums](https://github.com/sfzinstruments/karoryfer.big-rusty-drums)（Karoryfer Samples）: スネア4録音・クラッシュ2録音・キック1録音から加工した4素材。[出典と加工内容](assets/rusty-drums/README.md)、[ファイルごとの出典・ハッシュ](assets/rusty-drums/sources.json)、[ライセンス全文](assets/rusty-drums/LICENSE-CC0.txt)

## 操作

- パッドをクリックして試聴。パッドにフォーカスしてEnter/Spaceでも再生できます。
- カテゴリーや検索で絞り込み、ハートでお気に入りを保存できます。
- 下部のリピートで選択した音を繰り返し、順番に聴くで表示中の音を巡回します。
- WAVで選択した音を48kHz・16bit・モノラルで保存できます。
- 四角の停止ボタンまたはEscapeで、余韻も含めてすべて停止します。

お気に入りはそのブラウザのローカルストレージに保存します。音声は最初のクリックで開始します。今回は音色を比較するための試聴版で、ビートやフィルの自動生成は次の段階です。

音色には表示番号とは別に、並べ替えても変わらない固定キーがあります。旧番号を固定キーとして引き継ぐため、保存済みのお気に入りは同じ音色を指し続け、ノイズの乱数も番号変更の影響を受けません。音色を追加するときは未使用の固定キーを付け、表示番号はカテゴリー順に自動で振ります。

## 構成

- `sounds.js`: 音色名・カテゴリー・合成パラメーター
- `synth.js`: PCM合成、波形抽出、WAVエンコード
- `samples.js`: 同梱WAVの読み込みとPCMデコード
- `assets/drums/`: CC0実音素材と出典記録
- `assets/rusty-drums/`: 強打スネア・クラッシュ・キックのCC0実音素材と出典記録
- `assets/percussion/`: シェイカー・タンバリン・ボンゴ・コンガのCC0実音素材と出典記録
- `app.js`: 試聴・フィルター・保存・音声スケジューリング
- `styles.css`: レスポンシブな画面
- `server.mjs`: ローカルプレビュー用サーバー

`npm test` でカテゴリー順の連番、番号変更時のPCM保持、全音色の生成、音量の上限とスネアの音量補正、サンプル境界、短い減衰、チップノイズの停止時間、アタッククラッシュとロックキックの出だし、ファットスネアの低域、コンプによる密度の変化、実音パーカッションの出だしと余韻の差、リバースとスウェルの立ち上がり、電子タムの音程下降と高低差、実音素材のハッシュ、読み込み失敗からの復帰、WAV出力を確認できます。
