# 強打ドラム素材の出典

同梱した4つのWAVは **Big Rusty Drums** の中央強打・リムショット・17インチクラッシュ・24インチキックの実録素材を加工したものです。

- 提供: Karoryfer Samples
- ライブラリ: https://github.com/sfzinstruments/karoryfer.big-rusty-drums
- 参照リビジョン: `f07ce00df34a46b6b08375be56fe116cf15782bc`
- ライセンス: CC0 1.0 Universal（[原文](LICENSE-CC0.txt)）
- 元素材7ファイルの固定URL・SHA-256、加工後WAVのSHA-256: [sources.json](sources.json)

中央打ちは`sn_center_vl10_rr1`、リムショットは`sn_rims_vl6_rr1`の最も強いベロシティ層です。同じ打撃のtop・btmマイクを、録音時の時間関係を保って使用しています。スネアには遠いマイクやリバーブを加えていません。

## スネアの加工

1. top録音から140Hzの一次ローパス成分を引いて、低域の膨らみを抑制
2. btm録音から1200Hzの一次ローパス成分を引き、スナッピーの高域を抽出
3. topにbtmを混合（中央打ち0.24倍、リムショット0.28倍）
4. 混合音から2500Hzの一次ローパス成分を引いた信号を0.55倍で加算
5. 振幅がピークの2%を初めて超える位置の1ms手前から0.45秒を切り出し
6. DC成分を除去してピークを0.9に正規化し、始端0.3ms・終端15msをフェード
7. 元の44.1kHzを維持して16bit・モノラルPCM WAVへ変換

一次ローパスの係数は`1 - exp(-2π × 周波数 / サンプルレート)`です。切り出し位置・長さはsources.jsonにフレーム数で記録しています。素材準備にはPythonのsoundfile / NumPyを使用しました。サイトの実行には不要です。

試聴時にsounds.jsの指定に従って余韻をさらに短くし、48kHzへ補間します。基本のピーク0.78に音色ごとの音量補正を加え、ピークの上限を0.95未満に抑えます。波形表示・試聴・WAV保存に同じPCMを使います。

## アタッククラッシュの加工

`cr_vl5_rr1`の強いベロシティ層を使います。同じ打撃のオーバーヘッド（oh）と近接（cl）録音を、時間関係を保ったまま混ぜています。

1. ohにclを0.25倍で加算
2. 振幅がピークの2%を初めて超える位置の1ms手前から3秒を切り出し
3. `1 + 0.9 × exp(-t / 0.012)`を掛け、先頭の打撃を強調
4. DC成分を除去し、始端0.3ms・終端20msをフェード
5. `tanh(2 × 信号 / ピーク)`で軽くソフトクリップし、打撃の密度を上げる
6. ピークを0.9に正規化して、元の44.1kHzを維持した16bit・モノラルPCM WAVへ変換

試聴時には2.6秒の長さと減衰を適用します。元のVirtuosity Drumsのクラッシュはそのまま残し、別の音色として比較できます。

## ロックキックの加工

24インチキックの最も強いベロシティ層`k_vl14_rr1`を使います。専用キックマイクの録音だけを使用し、オーバーヘッドやスネアの共鳴は混ぜていません。

1. 30Hzの一次ローパス成分を引き、超低域の膨らみを抑制
2. 1500Hzの一次ローパス成分を引いた信号を0.6倍で加算し、ビーターの打撃を強調
3. 振幅がピークの2%を初めて超える位置の1ms手前から0.45秒を切り出し
4. DC成分を除去し、始端0.3ms・終端15msをフェード
5. ピークを0.9に正規化して、元の44.1kHzを維持した16bit・モノラルPCM WAVへ変換

試聴時には短い減衰を掛け、0.32秒に収めています。音量を+1dB補正し、ピークを滑らかに抑えます。元のアコースティックキックと並べて比較できます。
