# 実音素材の出典

同梱WAVは **Virtuosity Drums** の11個の実録素材を加工したものです。

- 提供: Versilian Studios / Karoryfer Samples
- ライブラリ: https://github.com/sfzinstruments/virtuosity_drums
- 参照リビジョン: `9f04cf9a734527edfbb0a4eee1f674e45bbf71bc`
- ライセンス: CC0 1.0 Universal（[原文](LICENSE-CC0.txt)）
- 元素材のパス・固定URL・SHA-256、加工後WAVのSHA-256: [sources.json](sources.json)

スネア3奏法、クラッシュ、ライド、ライドベル、カウベル、キック、タム高低、オープンハットを採用しています。スネアは近接マイク、キックは専用マイク、シンバル・タム・ハットはmidマイク、カウベルはcloseマイクの録音です。

## 同梱時の加工

1. 元素材をデコードし、複数チャンネルの場合は平均してモノラル化
2. 振幅がピークの2%を初めて超える位置の2ms手前から切り出し
3. 必要な余韻だけ残してカット（位置・長さはsources.jsonにフレーム数で記録）
4. DC成分を除去し、ピークを0.9に正規化
5. 始端0.5ms・終端15msをフェードし、16bit PCM WAVとして保存

元のサンプルレートを維持しています（カウベル44.1kHz、その他48kHz）。変換にはPythonのsoundfile / NumPyを使用しました。これらは素材準備時のみ使用し、サイトの実行には不要です。

試聴時にはsounds.jsの指定に従って速度・ピッチ、短い減衰、逆再生、フェードインを適用します。最終出力は48kHz・モノラル、ピーク0.78です。波形表示・試聴・WAV保存は同じ加工済みPCMを使います。

スプラッシュはクラッシュ素材の加工音、カウベルの高低とタム4音のうち2音はピッチ加工です。別の楽器を録音した素材としては扱っていません。
